 TechNest

TechNest is a simple product website created as a web development project.

The website showcases different technology products and provides basic information about each product, including:

- Product name
- Price
- Description
- Availability

It also includes a contact page where users can enter their name and email.

The website contains three main pages:

 Introduction to TechNest and featured products
 Displays the available technology products
  Contact form for users

 Technologies Used
- HTML
- CSS
- JavaScript

 Features
- Simple and clean design
- Navigation between pages
- Product information
- Check Availability buttons
- JavaScript welcome message
- Automatic current year in the footer
- Contact form with basic validation
